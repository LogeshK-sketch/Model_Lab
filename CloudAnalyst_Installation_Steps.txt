CLOUDANALYST INSTALLATION AND EXECUTION STEPS
Windows 10/11 | CMD + Winget

STEP 1: OPEN CMD AS ADMINISTRATOR
1. Press Win + S.
2. Search for Command Prompt.
3. Select Run as administrator.

STEP 2: INSTALL JAVA JDK 8
Run:
winget install --id EclipseAdoptium.Temurin.8.JDK -e

After installation, close CMD and open it again. Verify Java:
java -version
javac -version

Both commands should display version information.

STEP 3: INSTALL APACHE NETBEANS
Run:
winget install --id Apache.NetBeans -e

If Winget cannot find the package, search for the available package ID:
winget search NetBeans

Install NetBeans using the exact package ID shown in the results.

STEP 4: DOWNLOAD CLOUDANALYST
CloudAnalyst does not have a confirmed Winget package, so download it manually.
1. Open: https://sourceforge.net/projects/cloudanalystnetbeans/
2. Click Download.
3. Wait for the ZIP file to download.
4. Extract the ZIP file.

To open your Downloads folder from CMD, run:
explorer "%USERPROFILE%\Downloads"

STEP 5: OPEN CLOUDANALYST IN NETBEANS
1. Launch Apache NetBeans.
2. Click File > Open Project.
3. Browse to the folder where you extracted CloudAnalyst.
4. Select the project folder containing the NetBeans project files.
5. Click Open Project.
6. Wait for NetBeans to load the project.
7. Click the green Run button.

Follow your lab manual's instructions if an initial startup error appears.

STEP 6: RUN THE SIMULATION
1. When the CloudAnalyst GUI opens, configure the simulation settings required by your lab exercise.
2. Click Done.
3. Click Run Simulation.
4. Wait for the simulation to finish.
5. View the performance results and take screenshots for your lab record.

QUICK COMMAND SUMMARY
Run these commands one by one in CMD:

winget install --id EclipseAdoptium.Temurin.8.JDK -e
winget install --id Apache.NetBeans -e
java -version
javac -version
explorer "%USERPROFILE%\Downloads"

IMPORTANT NOTES
- CloudAnalyst itself must be downloaded manually unless a suitable Winget package is available.
- If Winget cannot find NetBeans, use "winget search NetBeans" and install using the exact ID displayed.
- If NetBeans cannot open the project or Java reports a compatibility error, note the exact error message and troubleshoot that specific issue.
